# 13. User Stories

User stories describe product behavior from the user's perspective.

Each story follows the format:

> **As a [role], I want [goal] so that [benefit].**

---

# Module 1 – Authentication

### US-001

As a new user,

I want to create an account

so that I can access SyncBoard.

---

### US-002

As a user,

I want to sign in securely

so that my data remains protected.

---

### US-003

As a user,

I want to log out

so that nobody can access my account.

---

### US-004

As a user,

I want to reset my password

so that I can recover my account.

---

### US-005

As a user,

I want to log in using Google

so that I don't have to remember another password.

---

# Module 2 – User Profile

### US-006

---

### US-007

As a user,

---

### US-008

### US-009

As a user,

# Module 3 – Workspace

### US-010

As a user,

I want to create a workspace

so that I can organize my projects.

---

### US-011

As a workspace owner,

I want to rename my workspace

so that it reflects my project.

---

### US-012

As an owner,

I want to invite members

so that we can collaborate.

---

### US-013

As an owner,

I want to assign roles

so that permissions remain controlled.

---

### US-014

As an owner,

I want to remove members

so that former collaborators lose access.

---

### US-015

As an owner,

I want to transfer ownership

so that another person can manage the workspace.

---
